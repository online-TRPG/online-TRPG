# Combat icon attribution

The SVG glyphs in this directory are generated from [Game Icons](https://github.com/game-icons/icons) and distributed under [CC BY 3.0](https://github.com/game-icons/icons/blob/master/license.txt).

Run `node scripts/generate-combat-icons.mjs` after changing the source mapping. Exact source glyph names are recorded in `manifest.json`.
